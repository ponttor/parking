# Parking Lot Backend Challenge

Platogo Backend Developer Challenge 2025.

## Tech stack

- Ruby 3.3.x
- Rails 7.x
- SQLite
- Minitest

## Setup

```bash
git clone <repo>
cd <repo>
bundle install
bin/rails db:create db:migrate
bin/rails s
```

## Tests

Run all tests with:

```bash
bin/rails test
```
